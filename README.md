I'm a sophomore at Berkeley studying economics and data science. Nearly everything I build is an AI tool that somebody then has to use at work. This past summer that meant conversational search over 880 commercial leases in plain English, built for the Empire State Building's landlord. Before that, a real-time voice agent qualifying calls for CRE brokers, and a candidate-screening platform for a global recruiting firm. Right now I'm building [CompLens](https://complens-ai.vercel.app/) solo, full stack.

Most of it starts as a spreadsheet someone is tired of maintaining.
